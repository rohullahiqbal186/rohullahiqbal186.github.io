Automatic scoring of BOT-2 drawing tasks

A two-stage deep learning pipeline that first recognizes which shape a drawing belongs to, then predicts the score an expert examiner would give it.

Status
Completed project
My role
Developed the pipeline and its models
Models
MobileNetV2, DenseNet121
Results
99% shape-classification accuracy; over 83% average scoring accuracy

Problem

The Bruininks-Oseretsky Test of Motor Proficiency, Second Edition (BOT-2) includes drawing items, such as copying a given shape. A trained examiner scores each drawing against written criteria. That takes time, and the result depends partly on the examiner's judgement.

I wanted to know whether a model could do two things an examiner does: recognize which item a drawing answers, and then give it the score an expert would.

Approach

I split the task in two. Each shape has its own scoring criteria, so one model scoring every shape would have to learn several rubrics at once.

  • Stage 1, shape classification. A CNN identifies which BOT-2 shape the drawing belongs to.
  • Stage 2, scoring. The drawing goes to a scoring model trained only on that shape. Depending on the item, the scoring model is binary or ordinal, so its output matches how that item is scored.

I used MobileNetV2 and DenseNet121 as backbones for these models.

Results

Shape classification reached 99% accuracy. The shape-specific scoring models reached an average scoring accuracy of over 83%.

The drawings were made by people taking the test, so I don't show any samples or share the data here.
